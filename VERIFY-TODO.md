# Verify before use

Every assumption in this repository that can only be confirmed in a real
environment, one row each. To use a row, read the assumption and run its
verification command in your own environment; what you see there is what
counts. The row ids (for example `P3-4`) are referenced from the READMEs and
comments of the other directories, so they stay stable.
